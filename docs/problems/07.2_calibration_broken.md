# Problem 04: Confidence calibration is broken — 32% wrong at "high confidence"

**Date:** Sept 14, 2026
**Where seen:** `docs/outputs/07_analysis_100q.txt`

## The observation

HopSense confidence buckets vs actual correctness:

| Confidence bucket | n | Correct | Accuracy |
|---|---|---|---|
| [0.00, 0.50) | 20 | 4 | 20% ✅ well-calibrated |
| [0.50, 0.70) | 4 | 3 | 75% |
| [0.70, 0.90) | 4 | 2 | 50% ⚠ |
| **[0.90, 1.01)** | **72** | **49** | **68%** 🚨 |

72% of all questions get "confidence ≥ 0.90" from the model — 
but nearly 1 in 3 of those are wrong. The model is systematically 
overconfident.

## Why it matters

Auric AI's JD literally names this failure mode:
> "a wrong answer delivered with false confidence is worse than 
> no answer"

For any real deployment (defense, medical, finance) this failure 
mode is disqualifying. It also breaks the whole point of confidence 
scores: if 0.9 doesn't mean 90%, users can't threshold on it.

## Why it happens (hypothesis)

The synthesizer prompt asks the LLM to "provide overall confidence 
0.0 to 1.0". LLMs are notoriously bad at introspective confidence 
estimation. They pattern-match to "if I have an answer, confidence 
is high."

We also propagate confidence via "chain is only as strong as the 
weakest link" — but each hop's confidence comes from the same 
overconfident LLM. The overconfidence compounds instead of 
correcting.

## Options

1. **Consistency-based confidence.** Sample the answer N times at 
   temperature > 0; confidence = fraction that agree. Grounded, 
   no LLM introspection required.
2. **Retrieval-based confidence.** Use retrieval scores (top passage 
   similarity, gap between top-1 and top-2) as signal instead of 
   LLM self-report.
3. **Calibration via post-hoc scaling** (isotonic regression / 
   temperature scaling) on a held-out set.
4. **Combined signal:** LLM self-report × retrieval score × 
   consistency. Weighted combination.

## Decision

Implement option 1 (consistency) first. Cheap, principled, 
well-established (Self-Consistency, Wang et al. 2022). Measure 
calibration change. If insufficient, add option 2 (retrieval 
score).

## Takeaway

LLM self-reported confidence looks unreliable in this setup — 
overconfident and poorly separated from accuracy. Systems that 
threshold on it for gating decisions likely ship false confidence. 
Motivates measuring calibration directly and treating confidence-vs-
accuracy as a first-class metric, not a nice-to-have.
